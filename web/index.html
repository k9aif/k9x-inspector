Tracked applications come from INSPECTOR_APPS in .env (and any the admin adds here). Each is re-inspected on every push (GitHub webhook) and on the schedule when its branch has moved.

The code is read, never run: Python is parsed to syntax trees and YAML is loaded as data. Public repositories only, unless the server holds a read-only token.
